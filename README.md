# DecorBlock

Minecraft NeoForge мод на **Kotlin**, добавляющий **2100+ декоративных блоков** для строительства: доски, паркет, черепицу, бетон, металл, камень, мрамор, терраццо, ковры, шерсть, стекло, неон, орнаменты и полублоки.

Никаких новых механик, крафтов с сюрпризами или мобов — только большая палитра для строителей. Блоки находятся во вкладке «Строительство» и ищутся по названию материала.

## Требования

- Minecraft **Java Edition 26.3**
- **NeoForge 26.3.0** или совместимая версия 26.3
- **Kotlin for Forge 6.4.0**

## Установка

Скачать `.jar` со страницы [Releases](../../releases) или с CurseForge и положить в папку `mods`.

## Сборка из исходников

```sh
git clone https://github.com/tmageko/decorblock.git
cd decorblock
./gradlew build
```

Готовый JAR появится в `build/libs/`. Модели блоков и предметов можно пересоздать командой `./gradlew runData`.
